# Soteria — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Agententeam aus fünf Rollen entscheidet bei einem Schaden im Güterverkehr in Minuten über eine Maßnahme, ohne dass eine Partei mehr erfährt, als die Need-to-know-Matrix erlaubt — mit getippten Ablehnungen, Freigabestufen und verketteten Quittungen.

**Architecture:** Das vorhandene Harness aus `collab-agent/` (Charter, Ledger, Team, 56 grüne Tests) wird als `soteria/` in das Repo `Backooo/Soteria` portiert. Die generische Übergabe `delegate_to_<rolle>(task, context)` mit Freitext wird ersetzt durch `ask_<rolle>(field, reason_code)`, das ausschließlich einen nach Matrix projizierten `FactSheet` zurückgibt — damit kann gar kein Freitext eine Grenze überqueren. Freigaben, Quarantäne und Quittungen kommen als neue Schichten dazu. Der Bewerter existiert zweimal: als Modellrolle für die Bühne und als deterministische Regelmaschine (`policy.py`) für die Zahlen.

```python
"""Getippte Umschlaege. Kein Freitext ueberquert je eine Rollengrenze.

Jede Grenzueberschreitung in Soteria ist eine Instanz aus diesem Modul. Die
Pruefung sitzt in `__post_init__`, damit ein ungueltiger Umschlag nicht
existieren kann -- nicht in einer Bitte an das Modell, sondern in Python.

Jede Ablehnung ist ein Code aus `REFUSAL`. Ein Satz als Ablehnungsgrund waere
nicht zaehlbar, und die Zahl der Ablehnungen ist eine unserer vier Messgroessen.
"""

from __future__ import annotations

import hashlib
import json
import time
from dataclasses import dataclass, field
from typing import Any, Mapping

# --- Wertelisten --------------------------------------------------------

ROLES: tuple[str, ...] = ("intake", "assessor", "legal", "supplier", "customer")

MEASURE: tuple[str, ...] = (
    "proceed",
    "hold",
    "cool",
    "reload",
    "alt_transport",
    "contact",
    "stop_train",
    "notify_authority",
    "press",
)

REASON: tuple[str, ...] = (
    "cost",
    "liability",
    "time",
    "safety",
    "feasibility",
    "confidentiality",
    "missing_data",
)

REFUSAL: tuple[str, ...] = (
    "not_in_matrix",
    "no_grant",
    "grant_mismatch",
    "quarantine",
    "budget",
    "quota",
    "unknown_field",
    "unknown_role",
    "bad_value",
)

FLAG: tuple[str, ...] = ("market_sensitive", "hazmat", "perishable", "person_data")

# Wie ein Feld eine Rolle erreicht. `none` heisst: gar nicht.
VISIBILITY: tuple[str, ...] = ("raw", "coarse", "ampel", "schwelle", "flag", "none")

AMPEL: tuple[str, ...] = ("gruen", "gelb", "rot")
SCHWELLE: tuple[str, ...] = ("above", "below")


class EnvelopeError(ValueError):
    """Eine getippte Ablehnung. `code` ist immer aus `REFUSAL`."""

    def __init__(self, code: str, detail: str = "") -> None:
        if code not in REFUSAL:
            raise ValueError(f"{code!r} is not a typed refusal; use one of {REFUSAL}")
        self.code = code
        self.detail = detail
        super().__init__(f"{code}: {detail}" if detail else code)


# --- kanonische Form und Quittungsmaterial ------------------------------


def canonical(payload: Any) -> str:
    """Eine Darstellung, die nicht von der Schluesselreihenfolge abhaengt.

    Grundlage fuer jeden Digest: eine Freigabe gilt fuer genau diese Parameter,
    und `{"a":1,"b":2}` muss dieselbe Freigabe treffen wie `{"b":2,"a":1}`.
    """
    return json.dumps(payload, sort_keys=True, separators=(",", ":"), default=str)


def digest(payload: Any) -> str:
    return hashlib.sha256(canonical(payload).encode("utf-8")).hexdigest()[:16]


def _require(condition: bool, code: str, detail: str) -> None:
    if not condition:
        raise EnvelopeError(code, detail)


def _require_role(name: str, what: str) -> None:
    _require(name in ROLES, "unknown_role", f"{what}={name!r} is not one of {ROLES}")


def _require_measures(measures: tuple[str, ...]) -> None:
    _require(bool(measures), "bad_value", "at least one measure is required")
    unknown = [m for m in measures if m not in MEASURE]
    _require(not unknown, "bad_value", f"unknown measures {unknown}")
    _require(len(set(measures)) == len(measures), "bad_value", "a measure is listed twice")
```

```python
"""Die Need-to-know-Matrix: wer welches Feld in welcher Auflösung sieht.

Das ist das Produkt. Nicht die Prompts, nicht die Rollenbeschreibungen -- diese
Tabelle, geprueft in Python, bevor ein Modell laeuft.

Drei Begriffe:

- **Eigentuemer**: die Stelle, die den Rohwert haelt. Muss keine Agentenrolle
  sein: `route_weakness` und `market_sensitive` gehoeren `infra`, einer
  Datenquelle im Szenario. Sonst gaebe es fuer diese Felder keine Quelle.
- **Sichtbarkeit**: `raw` (Klartext), `coarse` (Grobklasse), `ampel`
  (gruen/gelb/rot), `schwelle` (above/below), `flag` (bool), `none` (gar nicht).
- **Projektor**: die Funktion, die den Rohwert in genau die erlaubte Auflösung
  verwandelt. Der Bewerter erfaehrt **dass** der Bestand kritisch ist, nie
  **wie hoch** er ist.

Ein Aufruf mit `none` wirft `EnvelopeError("not_in_matrix")`. Das ist der
Ablehnungscode, der in der Demo auf dem Schirm erscheint.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Callable, Mapping

from .envelope import ROLES, VISIBILITY, EnvelopeError

# Schwellen an einer Stelle, damit ein Szenario sie ueberschreiben kann, ohne
# dass irgendwo eine Zahl im Code klebt.
DEFAULT_THRESHOLDS: dict[str, Any] = {
    # Bestandsdeckung in Tagen: unter 1 rot, unter 3 gelb, sonst gruen.
    "stock_days_red": 1.0,
    "stock_days_amber": 3.0,
    # Vertragsstrafe in Euro, ab der die Schwelle "above" meldet.
    "penalty_eur": 50_000,
    # Ersatz: Ankunft in Minuten, bis zu der er als gruen gilt.
    "replacement_eta_amber_min": 120,
    # Temperatur: Abstand zur Grenze in Kelvin, unter dem es gelb wird.
    "temp_margin_k": 2.0,
    # Minuten ausserhalb des Fensters, ab denen es gelb wird.
    "temp_minutes_out_amber": 15,
    # Streckenschwaeche als Schwere 0..3.
    "route_severity_red": 3,
}

# Grobklassen fuer `cargo_class`. Wer nur `coarse` sieht, erfaehrt die
# Regulierungslage, nicht die Ware.
CARGO_COARSE: dict[str, str] = {
    "pharma_cooled": "regulated",
    "vaccine": "regulated",
    "chem_hazmat": "hazardous",
    "fuel": "hazardous",
    "fresh_food": "perishable",
    "flowers": "perishable",
    "machine_parts": "general",
    "steel": "general",
}


def _number(raw: Any, what: str) -> float:
    try:
        return float(raw)
    except (TypeError, ValueError):
        raise EnvelopeError("bad_value", f"{what} expects a number, got {raw!r}") from None


def _mapping(raw: Any, what: str) -> Mapping[str, Any]:
    if not isinstance(raw, Mapping):
        raise EnvelopeError("bad_value", f"{what} expects an object, got {type(raw).__name__}")
    return raw


# --- Projektoren --------------------------------------------------------


def _raw(raw: Any, thresholds: Mapping[str, Any]) -> Any:
    return raw


def _coarse_cargo(raw: Any, thresholds: Mapping[str, Any]) -> str:
    return CARGO_COARSE.get(str(raw), "general")


def _ampel_stock(raw: Any, thresholds: Mapping[str, Any]) -> str:
    days = _number(raw, "customer_stock")
    if days < float(thresholds["stock_days_red"]):
        return "rot"
    if days < float(thresholds["stock_days_amber"]):
        return "gelb"
    return "gruen"


def _schwelle_penalty(raw: Any, thresholds: Mapping[str, Any]) -> str:
    return "above" if _number(raw, "contract_penalty") > float(thresholds["penalty_eur"]) else "below"


def _ampel_temperature(raw: Any, thresholds: Mapping[str, Any]) -> str:
    curve = _mapping(raw, "temperature_curve")
    current = _number(curve.get("current_c"), "temperature_curve.current_c")
    limit = _number(curve.get("limit_c"), "temperature_curve.limit_c")
    minutes_out = _number(curve.get("minutes_out", 0), "temperature_curve.minutes_out")
    if current > limit:
        return "rot"
    if limit - current <= float(thresholds["temp_margin_k"]) or minutes_out >= float(
        thresholds["temp_minutes_out_amber"]
    ):
        return "gelb"
    return "gruen"


def _ampel_replacement(raw: Any, thresholds: Mapping[str, Any]) -> str:
    offer = _mapping(raw, "replacement_available")
    if not bool(offer.get("available")):
        return "rot"
    eta = _number(offer.get("eta_min", 0), "replacement_available.eta_min")
    return "gruen" if eta <= float(thresholds["replacement_eta_amber_min"]) else "gelb"


def _ampel_route(raw: Any, thresholds: Mapping[str, Any]) -> str:
    severity = _number(raw, "route_weakness")
    if severity >= float(thresholds["route_severity_red"]):
        return "rot"
    return "gelb" if severity > 0 else "gruen"


def _flag(raw: Any, thresholds: Mapping[str, Any]) -> bool:
    """Ein Flag ist immer ein bool. Ein Text wuerde Inhalt durchlassen."""
    return bool(raw)


@dataclass(frozen=True)
class Field:
    """Ein Feld mit Eigentuemer, Sichtbarkeiten und Projektoren je Auflösung."""

    name: str
    owner: str
    kind: str
    visibility: Mapping[str, str]
    projectors: Mapping[str, Callable[[Any, Mapping[str, Any]], Any]]

    def __post_init__(self) -> None:
        missing = [r for r in ROLES if r not in self.visibility]
        if missing:
            raise EnvelopeError("bad_value", f"{self.name} says nothing about {missing}")
        bad = [v for v in self.visibility.values() if v not in VISIBILITY]
        if bad:
            raise EnvelopeError("bad_value", f"{self.name} has unknown visibilities {bad}")
        needed = {v for v in self.visibility.values() if v != "none"}
        absent = sorted(needed - set(self.projectors))
        if absent:
            raise EnvelopeError("bad_value", f"{self.name} lacks projectors for {absent}")

    def project(self, raw: Any, role: str, thresholds: Mapping[str, Any]) -> Any:
        level = self.visibility.get(role)
        if level is None:
            raise EnvelopeError("unknown_role", f"{role!r} is not one of {ROLES}")
        if level == "none":
            raise EnvelopeError(
                "not_in_matrix", f"{self.name} is not visible to {role}"
            )
        return self.projectors[level](raw, thresholds)


def _field(
    name: str,
    owner: str,
    kind: str,
    vis: Mapping[str, str],
    projectors: Mapping[str, Callable[[Any, Mapping[str, Any]], Any]],
) -> Field:
    full = {role: vis.get(role, "none") for role in ROLES}
    return Field(name=name, owner=owner, kind=kind, visibility=full, projectors=projectors)

    f.name: f
    for f in (

# --- Zugriff ------------------------------------------------------------


def _field_or_refuse(name: str) -> Field:
    try:
        return FIELDS[name]
    except KeyError:
        raise EnvelopeError("unknown_field", f"{name!r} is not a declared field") from None


def visibility(field_name: str, role: str) -> str:
    fld = _field_or_refuse(field_name)
    if role not in ROLES:
        raise EnvelopeError("unknown_role", f"{role!r} is not one of {ROLES}")
    return fld.visibility[role]


def project(field_name: str, raw: Any, role: str, thresholds: Mapping[str, Any]) -> Any:
    """Den Rohwert in genau die Auflösung bringen, die `role` haben darf."""
    return _field_or_refuse(field_name).project(raw, role, thresholds)


def fields_for(role: str) -> tuple[str, ...]:
    """Alle Felder, die `role` ueberhaupt erreichen koennen."""
    if role not in ROLES:
        raise EnvelopeError("unknown_role", f"{role!r} is not one of {ROLES}")
    return tuple(n for n, f in FIELDS.items() if f.visibility[role] != "none")


def owners() -> dict[str, str]:
    return {name: f.owner for name, f in FIELDS.items()}


def matrix_table() -> str:
    """Die Tabelle als Markdown -- fuer README, Demo und Ereignisvertrag."""
    head = "| Feld | Eigentuemer | " + " | ".join(ROLES) + " |"
    rule = "|---" * (len(ROLES) + 2) + "|"
    lines = [head, rule]
    for name in FIELDS:
        fld = FIELDS[name]
        cells = [("—" if fld.visibility[r] == "none" else fld.visibility[r]) for r in ROLES]
        lines.append(f"| `{name}` | {fld.owner} | " + " | ".join(cells) + " |")
    return "\n".join(lines)
```

```python
"""Selbstbedienung fuer den Datenstrang: prueft Szenariodateien ohne Modell und Netz.

    uv run python scripts/validate_scenarios.py                  # alle
    uv run python scripts/validate_scenarios.py <pfad> [<pfad>]  # einzelne

Leere Ausgabe und Rueckgabewert 0 heisst: in Ordnung. Jede Meldung nennt die
Datei, den Schluesselpfad und was erwartet war.
"""

from __future__ import annotations

import json
import sys
from pathlib import Path
from typing import Any

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from soteria.envelope import FLAG, MEASURE, REASON, REFUSAL, ROLES
from soteria.grants import TIER
from soteria.matrix import CARGO_COARSE, DEFAULT_THRESHOLDS, FIELDS, owners

SCENARIO_DIR = Path(__file__).resolve().parents[1] / "soteria" / "scenarios"

_SHAPES: dict[str, str] = {
    "cargo_class": "string",
    "temperature_curve": "curve",
    "customer_stock": "number",
    "contract_penalty": "number",
    "route_weakness": "int0to3",
    "contact_person": "string",
    "replacement_available": "offer",
    "market_sensitive": "bool",
}


def _check_shape(field: str, value: Any, where: str, out: list[str]) -> None:
    shape = _SHAPES.get(field)
    if shape == "string" and not isinstance(value, str):
        out.append(f"{where}: {field} must be a string, got {type(value).__name__}")
    elif shape == "number" and not isinstance(value, (int, float)) or isinstance(value, bool) and shape == "number":
        if shape == "number":
            out.append(f"{where}: {field} must be a number, got {value!r}")
    elif shape == "bool" and not isinstance(value, bool):
        out.append(f"{where}: {field} must be true or false, got {value!r}")
    elif shape == "int0to3":
        if not isinstance(value, int) or isinstance(value, bool) or not 0 <= value <= 3:
            out.append(f"{where}: {field} must be an integer 0..3, got {value!r}")
    elif shape == "curve":
        if not isinstance(value, dict):
            out.append(f"{where}: {field} must be an object")
        else:
            for key in ("setpoint_c", "current_c", "limit_c"):
                if not isinstance(value.get(key), (int, float)) or isinstance(value.get(key), bool):
                    out.append(f"{where}: {field}.{key} must be a number")
            if "minutes_out" in value and not isinstance(value["minutes_out"], (int, float)):
                out.append(f"{where}: {field}.minutes_out must be a number")
    elif shape == "offer":
        if not isinstance(value, dict):
            out.append(f"{where}: {field} must be an object")
        else:
            if not isinstance(value.get("available"), bool):
                out.append(f"{where}: {field}.available must be true or false")
            if not isinstance(value.get("eta_min", 0), (int, float)):
                out.append(f"{where}: {field}.eta_min must be a number")


def validate(path: Path) -> list[str]:
    """Return a list of problems; an empty list means the file is fine."""
    out: list[str] = []
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except json.JSONDecodeError as exc:
        return [f"{path.name}: not valid JSON -- {exc}"]
    if not isinstance(data, dict):
        return [f"{path.name}: top level must be an object"]

    name = path.name
    for key in ("id", "title", "report", "facts", "truth"):
        if key not in data:
            out.append(f"{name}: missing required key {key!r}")
    if data.get("id") and data["id"] != path.stem:
        out.append(f"{name}: id={data['id']!r} does not match the filename {path.stem!r}")

    report = data.get("report")
    if isinstance(report, dict):
        for key in ("incident_id", "location", "ts", "cargo_class", "symptom", "reporter_role"):
            if key not in report:
                out.append(f"{name}: report is missing {key!r}")
        if report.get("reporter_role") not in ROLES:
            out.append(f"{name}: report.reporter_role={report.get('reporter_role')!r} not in {ROLES}")
        if not isinstance(report.get("ts"), (int, float)) or not report.get("ts", 0) > 0:
            out.append(f"{name}: report.ts must be a positive unix timestamp")
        if report.get("cargo_class") not in CARGO_COARSE:
            out.append(
                f"{name}: WARNING report.cargo_class={report.get('cargo_class')!r} is unknown "
                f"and will coarsen to 'general'; known: {sorted(CARGO_COARSE)}"
            )
    elif report is not None:
        out.append(f"{name}: report must be an object")

    facts = data.get("facts")
    field_owner = owners()
    if isinstance(facts, dict):
        seen: set[str] = set()
        for holder, group in facts.items():
            if holder not in set(ROLES) | {"infra"}:
                out.append(f"{name}: facts has unknown owner {holder!r}; use one of {sorted(set(ROLES) | {'infra'})}")
                continue
            if not isinstance(group, dict):
                out.append(f"{name}: facts.{holder} must be an object")
                continue
            for field_name, value in group.items():
                if field_name not in FIELDS:
                    out.append(f"{name}: facts.{holder}.{field_name} is not a declared field")
                    continue
                expected = field_owner[field_name]
                if expected != holder:
                    out.append(
                        f"{name}: facts.{holder}.{field_name} belongs to {expected!r}; "
                        "a fact under the wrong owner is exactly the leak the matrix prevents"
                    )
                seen.add(field_name)
                _check_shape(field_name, value, f"{name}: facts.{holder}", out)
        for field_name in FIELDS:
            if field_name not in seen:
                out.append(f"{name}: WARNING no raw value for {field_name!r}; the assessor will see a gap")
    elif facts is not None:
        out.append(f"{name}: facts must be an object")

    for flag in data.get("flags", []) or []:
        if flag not in FLAG:
            out.append(f"{name}: flags has unknown {flag!r}; use {FLAG}")

    for key in (data.get("thresholds") or {}):
        if key not in DEFAULT_THRESHOLDS:
            out.append(f"{name}: thresholds has unknown key {key!r}; known: {sorted(DEFAULT_THRESHOLDS)}")

    for role in data.get("offline_roles", []) or []:
        if role not in ROLES:
            out.append(f"{name}: offline_roles has unknown role {role!r}")
        if role == "assessor":
            out.append(f"{name}: the assessor cannot be offline -- it is the one deciding")

    for i, key in enumerate(data.get("keys", []) or []):
        if not isinstance(key, dict):
            out.append(f"{name}: keys[{i}] must be an object")
            continue
        human = key.get("human_id")
        if not isinstance(human, str) or not human.strip():
            out.append(f"{name}: keys[{i}].human_id is missing")
        elif human in ROLES:
            out.append(f"{name}: keys[{i}].human_id={human!r} is a role; an agent cannot sign a grant")
        if key.get("measure") not in MEASURE:
            out.append(f"{name}: keys[{i}].measure={key.get('measure')!r} is not a measure")
        if "params" in key and not isinstance(key["params"], dict):
            out.append(f"{name}: keys[{i}].params must be an object")

    truth = data.get("truth")
    if isinstance(truth, dict):
        measures = truth.get("measures")
        if not isinstance(measures, list) or not measures:
            out.append(f"{name}: truth.measures must be a non-empty list")
        else:
            unknown = [m for m in measures if m not in MEASURE]
            if unknown:
                out.append(f"{name}: truth.measures has unknown {unknown}")
            else:
                expected_tier = max(TIER[m] for m in measures)
                if truth.get("tier") != expected_tier:
                    out.append(
                        f"{name}: truth.tier={truth.get('tier')!r} but {measures} implies {expected_tier}"
                    )
                keys_needed = {1: 0, 2: 1, 3: 2}[expected_tier]
                given = {k.get("human_id") for k in (data.get("keys") or []) if isinstance(k, dict)}
                if truth.get("expect_refusal") is None and len(given) < keys_needed:
                    out.append(
                        f"{name}: tier {expected_tier} needs {keys_needed} distinct keys, "
                        f"{len(given)} given -- add keys or set truth.expect_refusal"
                    )
        if truth.get("reason_code") not in REASON:
            out.append(f"{name}: truth.reason_code={truth.get('reason_code')!r} not in {REASON}")
        refusal = truth.get("expect_refusal")
        if refusal is not None and refusal not in REFUSAL:
            out.append(f"{name}: truth.expect_refusal={refusal!r} not in {REFUSAL}")
        if not str(truth.get("why", "")).strip():
            out.append(f"{name}: truth.why must say in one sentence why this is right")
    elif truth is not None:
        out.append(f"{name}: truth must be an object")

    return out


def main() -> int:
    paths = [Path(a) for a in sys.argv[1:]] or sorted(SCENARIO_DIR.glob("*.json"))
    if not paths:
        print(f"no scenario files in {SCENARIO_DIR}", file=sys.stderr)
        return 1
    errors = 0
    for path in paths:
        problems = validate(path)
        for line in problems:
            print(line)
        errors += sum(1 for p in problems if "WARNING" not in p)
    if errors:
        print(f"\n{errors} problem(s) in {len(paths)} file(s)", file=sys.stderr)
    return 1 if errors else 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""Die Nachfrage als Werkzeug, dessen Schema keinen Freitext zulaesst.

Das geerbte Harness bietet `delegate_to_<rolle>(task, context)` an -- zwei
string-Parameter. Damit ist "kein Freitext ueber die Grenze" eine Bitte im
Prompt. Hier nimmt das Werkzeug einen Feldnamen aus einem Enum und einen Grund
aus einem Enum. Es gibt keine Stelle, an der ein Satz hineinpasst.

Die Antwort ist immer ein `FactSheet` mit **projizierten** Werten: der Bewerter
erfaehrt `"rot"`, nie `0.5`. Jede Verweigerung ist ein `EnvelopeError` mit einem
Code aus `REFUSAL`, damit sie zaehlbar und anzeigbar ist.
"""

from __future__ import annotations

from typing import Any, Mapping

from .envelope import FLAG, REASON, ROLES, EnvelopeError, FactSheet
from .matrix import FIELDS, fields_for, owners, project, visibility

ASK_PREFIX = "ask_"

# `route_weakness` und `market_sensitive` gehoeren `infra`, keiner Rolle. Der
# Betreiber meldet sie ueber die Aufnahme, also antwortet `intake` darauf --
# ohne den Rohwert selbst sehen zu duerfen.
INFRA_SPEAKER = "intake"


def askable_fields(target: str) -> tuple[str, ...]:
    """Die Felder, nach denen man `target` ueberhaupt fragen kann.

    Das sind die Felder, deren Eigentuemer `target` ist, plus die
    `infra`-Felder, wenn `target` der Sprecher fuer `infra` ist.
    """
    if target not in ROLES:
        raise EnvelopeError("unknown_role", f"{target!r} is not one of {ROLES}")
    field_owner = owners()
    out = [n for n, owner in field_owner.items() if owner == target]
    if target == INFRA_SPEAKER:
        out += [n for n, owner in field_owner.items() if owner == "infra"]
    return tuple(sorted(out))


def ask_tool(target: str, askable: tuple[str, ...]) -> dict[str, Any]:
    """Das Funktionsschema, mit dem eine Rolle `target` nach einem Feld fragt."""
    return {
        "type": "function",
        "name": f"{ASK_PREFIX}{target}",
        "description": (
            f"Frage die Rolle {target} nach genau einem Feld. Die Antwort ist eine "
            "Ampel, eine Schwelle oder ein Rohwert -- je nachdem, was die "
            "Need-to-know-Matrix dir zugesteht. Freitext gibt es nicht."
        ),
        "parameters": {
            "type": "object",
            "properties": {
                "field": {
                    "type": "string",
                    "enum": list(askable),
                    "description": f"Eines der Felder, die {target} halten kann.",
                },
                "reason_code": {
                    "type": "string",
                    "enum": list(REASON),
                    "description": "Warum du es brauchst. Ein Code, kein Satz.",
                },
            },
            "required": ["field", "reason_code"],
            "additionalProperties": False,
        },
    }


class FactStore:
    """Die Rohwerte eines Szenarios, gruppiert nach Eigentuemer.

    `answer()` ist die einzige Stelle, an der ein Rohwert gelesen wird, und sie
    gibt nie einen Rohwert heraus, den die Matrix dem Fragenden nicht zugesteht.
    """

    def __init__(
        self,
        facts: Mapping[str, Mapping[str, Any]],
        thresholds: Mapping[str, Any],
        offline_roles: tuple[str, ...] = (),
        flags: tuple[str, ...] = (),
    ) -> None:
        self._facts = {k: dict(v) for k, v in facts.items()}
        self._thresholds = dict(thresholds)
        self._offline = tuple(offline_roles)
        unknown = [f for f in flags if f not in FLAG]
        if unknown:
            raise EnvelopeError("bad_value", f"unknown flags {unknown}")
        self._flags = tuple(flags)

    @property
    def offline_roles(self) -> tuple[str, ...]:
        return self._offline

    @property
    def flags(self) -> tuple[str, ...]:
        return self._flags

    def owner_of(self, field: str) -> str:
        try:
            return FIELDS[field].owner
        except KeyError:
            raise EnvelopeError("unknown_field", f"{field!r} is not a declared field") from None

    def answer(self, asker: str, target: str, field: str) -> FactSheet:
        """Die projizierte Antwort von `target` an `asker` auf `field`."""
        if asker not in ROLES:
            raise EnvelopeError("unknown_role", f"asker {asker!r} is not one of {ROLES}")
        if target not in ROLES:
            raise EnvelopeError("unknown_role", f"target {target!r} is not one of {ROLES}")
        if field not in FIELDS:
            raise EnvelopeError("unknown_field", f"{field!r} is not a declared field")

        if field not in askable_fields(target):
            raise EnvelopeError(
                "unknown_field",
                f"{target} does not hold {field}; its owner is {self.owner_of(field)}",
            )
        if target in self._offline:
            raise EnvelopeError("quota", f"{target} did not answer in time")

        holder = self.owner_of(field)
        group = self._facts.get(holder, {})
        if field not in group:
            raise EnvelopeError(
                "unknown_field", f"this incident carries no raw value for {field}"
            )

        # Projektion nach der Matrix. Wirft `not_in_matrix`, wenn `asker` das
        # Feld gar nicht sehen darf. Das ist die eigentliche Grenze.
        value = project(field, group[field], asker, self._thresholds)
        return FactSheet(role=target, fields={field: value}, flags=self._flags)

    def visibility_for(self, asker: str, field: str) -> str:
        return visibility(field, asker)

    def can_receive(self, asker: str) -> tuple[str, ...]:
        return fields_for(asker)
```

# Architekturrevision v2 — drei Parteien als echte SuperNodes

**Stand 13:45, nach dem Gespräch mit Flower.** Diese Revision ersetzt die Rollenverteilung aus Abschnitt „Architektur". Alles aus Phase 0 (Tasks 1–5) gilt unverändert weiter — `envelope.py`, `matrix.py`, das Szenarioschema und der Ereignisvertrag sind genau die Bausteine, die v2 braucht.

## Was die Plattform hergibt — am Quellcode geprüft, nicht erinnert

Geprüft in `flwr` 1.36, installiert unter `collab-agent/.venv/.../flwr/`:

| Befund | Beleg |
|---|---|
| `AgentSession` hat nur `responses`, `connectors`, `events` — **kein `Grid`** | `flwr/agentapp/base.py:64-83` |
| Nur `ServerApp` hat `Grid`: `create_message`, `get_node_ids`, `push_messages`, `pull_messages`, `send_and_receive` | `flwr/serverapp/grid/grid.py:44-124` |
| `ClientApp` beantwortet beliebige Nachrichtentypen: `@app.query("<action>")` → `query.<action>` | `flwr/clientapp/client_app.py:275-310` |
| **`FLWR_RUNTIME_BASE_URL` und `FLWR_RUNTIME_API_KEY` werden ausschließlich für AgentApps gesetzt** | `flwr/supercore/task_process/agent/run_agentapp.py:76-77` |
| Ein FAB darf `agentapp`, `serverapp` und `clientapp` gleichzeitig deklarieren; ist `agentapp` gesetzt, sind die anderen zwei optional | `flwr/common/config.py:355-388` |
| Eine SuperNode-Identität kommt aus `--node-config 'party="customer"'`, lesbar als `context.node_config["party"]` | `flower-supernode --help` |

**Die harte Folge:** Modellzugang und Föderationszugang treffen sich in 1.36 nicht. Ein AgentApp hat das Modell, erreicht aber keinen SuperNode. Ein ClientApp läuft auf der Maschine der Partei, bekommt aber kein Modell von Flower Runtime. Wer behauptet, seine Agenten telefonierten über Föderationsgrenzen, hat die Kopplung selbst gebaut. Wir bauen sie nicht — wir nutzen die Trennung als Merkmal.

## Warum die Trennung ein Merkmal ist

Eine Projektion braucht kein Modell. `matrix.project("customer_stock", 0.5, "assessor", …) == "rot"` ist eine Funktion, keine Inferenz. Also läuft sie auf dem SuperNode der Partei — und damit gilt:

> **Der Rohwert verlässt die Maschine der Partei physisch nie.** Nicht, weil ein Prompt es verbietet. Nicht, weil ein Supervisor sich zurückhält. Weil auf dem Draht nur `"rot"` liegt und die `0.5` nie serialisiert wurde.

Das ist beweisbar statt behauptet: man kann den Nachrichtenverkehr mitschneiden und nachsehen. Das ist die stärkste Aussage, die an diesem Tag zu haben ist, und sie kostet uns, dass die Datenknoten kein Modell haben. Die Partei muss der Föderation also auch kein Modell leihen — was, nebenbei, genau der Grund ist, warum eine Partei überhaupt mitmachen würde.

## Die Topologie

```
 Föderation (ein SuperLink, drei getrennt betriebene Knoten)
 ┌──────────────────────────────────────────────────────────────────┐
 │                                                                  │
 │   ServerApp  ──  assessor (Bewerter, Mediator)                   │
 │       │          entscheidet auf Ampeln und Schwellen,           │
 │       │          hält null Rohwerte, Grid-Nachrichten            │
 │       │                                                          │
 │       ├── query.ask_field ──▶ SuperNode  party="carrier"         │
 │       │                       intake + legal                     │
 │       │                       roh: temperature_curve,            │
 │       │                            contract_penalty, infra       │
 │       │                                                          │
 │       ├── query.ask_field ──▶ SuperNode  party="customer"        │
 │       │                       roh: customer_stock, contact_person│
 │       │                                                          │
 │       └── query.ask_field ──▶ SuperNode  party="supplier"        │
 │                               roh: cargo_class,                  │
 │                                    replacement_available         │
 └──────────────────────────────────────────────────────────────────┘

 Daneben, auf demselben Code:
 AgentApp (SuperExec, hat das Modell) — fährt die Modellrollen und
 die Ask-Schleife mit ask_<rolle>, für die Bühne und die Erzählung.
```

**Sprachregelung, damit niemand uns bei einer Überbehauptung erwischt.** Was wir bauen, ist **eine** Flower-Föderation mit **drei getrennt betriebenen Parteiknoten**. „Eine Föderation je Partei" hieße drei SuperLinks, und ein ServerApp kann nur die Knoten *seines* SuperLink erreichen — das gibt 1.36 nicht her. In der Demo sagen wir „drei Parteien, drei Maschinen, eine Föderation" und im README steht der Befund aus der Tabelle oben. Wer will, startet die drei SuperNodes auf drei Rechnern; der Code merkt keinen Unterschied.

## Was sich an den Rollen ändert

| v1 | v2 | Warum |
|---|---|---|
| fünf Modellrollen in einer AgentApp | `assessor` ist der ServerApp; `intake`+`legal` sitzen auf dem Knoten `carrier`; `customer` und `supplier` je ein eigener Knoten | drei Parteien, drei Maschinen |
| `ask_<rolle>` als synthetisches Modellwerkzeug | bleibt — in der AgentApp. Im ServerApp ist es eine `Grid`-Nachricht `query.ask_field` | derselbe Umschlag, zwei Transporte |
| `FactStore` liest alle Rohwerte in einem Prozess | `FactStore` wird auf jedem Knoten mit **nur den eigenen** Rohwerten instanziiert | ein Knoten kann nicht herausgeben, was er nicht hat |
| `soteria/roles.py` Charter über fünf Rollen | bleibt unverändert für die AgentApp-Seite | der Charter beschreibt die Modellrollen, nicht die Knoten |

**Der schärfste Teil:** auf dem Knoten `customer` existiert `contract_penalty` nicht im Speicher. Ein Leck ist dort nicht verboten, es ist *unmöglich*. Das ersetzt keinen der Tests — die Matrix muss trotzdem greifen, denn der Bewerter fragt weiterhin den falschen Knoten, und dann muss `not_in_matrix` kommen.

```python
"""Der Draht zwischen dem Bewerter und den Parteiknoten.

Eine Flower-Nachricht traegt einen `RecordDict`. Ein `ConfigRecord` darin nimmt
nur Skalare und Skalarlisten auf (`flwr/common/typing.py:24-26`). Das ist hier
kein Hindernis, sondern der zweite Riegel: eine Projektion ist immer ein Skalar
(`"rot"`, `"above"`, eine Zahl, ein bool), ein Rohobjekt ist keiner. Ein
`temperature_curve`-Dict laesst sich also gar nicht verschicken.

`fact_record()` erzwingt das, statt es zu hoffen -- und wirft `bad_value`, wenn
jemand es versucht. Die Matrix und der Transport pruefen damit unabhaengig
voneinander dasselbe, und ein Fehler in der einen Schicht reisst die andere
nicht mit.
"""

from __future__ import annotations

import json
from pathlib import Path
from typing import Any

from flwr.app import ConfigRecord, RecordDict

from .envelope import FLAG, REASON, ROLES, EnvelopeError

ASK_FIELD = "query.ask_field"
RECORD_KEY = "soteria"
SCALARS = (str, int, float, bool)

SCENARIO_DIR = Path(__file__).resolve().parent / "scenarios"


def ask_record(asker: str, field: str, reason_code: str, incident_id: str) -> ConfigRecord:
    """Die Nachfrage als Record. Vier Skalare, kein Freitext."""
    if asker not in ROLES:
        raise EnvelopeError("unknown_role", f"{asker!r} is not one of {ROLES}")
    if reason_code not in REASON:
        raise EnvelopeError("bad_value", f"reason_code={reason_code!r} is not one of {REASON}")
    return ConfigRecord(
        {"asker": asker, "field": field, "reason_code": reason_code, "incident_id": incident_id}
    )


def read_ask(record: ConfigRecord) -> tuple[str, str, str, str]:
    """(asker, field, reason_code, incident_id) aus einem Nachfrage-Record."""
    try:
        return (
            str(record["asker"]),
            str(record["field"]),
            str(record["reason_code"]),
            str(record["incident_id"]),
        )
    except KeyError as exc:
        raise EnvelopeError("bad_value", f"ask record is missing {exc.args[0]!r}") from None


def fact_record(
    role: str, field: str, visibility: str, value: Any, flags: tuple[str, ...]
) -> ConfigRecord:
    """Die projizierte Antwort als Record.

    Wirft `bad_value`, wenn `value` kein Skalar ist. Das ist der Riegel: ein
    Rohobjekt kann den Knoten der Partei nicht verlassen.
    """
    if not isinstance(value, SCALARS):
        raise EnvelopeError(
            "bad_value",
            f"{field} projected to {type(value).__name__}, which is not a scalar; "
            "a raw object must never reach the wire",
        )
    unknown = [f for f in flags if f not in FLAG]
    if unknown:
        raise EnvelopeError("bad_value", f"unknown flags {unknown}")
    return ConfigRecord(
        {
            "role": role,
            "field": field,
            "visibility": visibility,
            # bool ist in Python eine Zahl; als String bliebe die Ampel und das
            # Flag nicht unterscheidbar. Der Typ steht in `visibility`.
            "value": value,
            "code": "",
            "flags": list(flags),
        }
    )


def refusal_record(actor: str, field: str, code: str) -> ConfigRecord:
    """Eine getippte Ablehnung als Record. Traegt niemals einen Wert."""
    from .envelope import REFUSAL

    if code not in REFUSAL:
        raise EnvelopeError("bad_value", f"{code!r} is not a typed refusal")
    return ConfigRecord(
        {"role": actor, "field": field, "visibility": "none", "value": "", "code": code, "flags": []}
    )


def read_reply(record: ConfigRecord) -> dict[str, Any]:
    out = {
        "role": str(record.get("role", "")),
        "field": str(record.get("field", "")),
        "visibility": str(record.get("visibility", "none")),
        "value": record.get("value", ""),
        "code": str(record.get("code", "")),
        "flags": [str(f) for f in (record.get("flags") or [])],
    }
    return out


def wrap(record: ConfigRecord) -> RecordDict:
    return RecordDict({RECORD_KEY: record})


def unwrap(records: RecordDict) -> ConfigRecord:
    try:
        return records[RECORD_KEY]
    except KeyError:
        raise EnvelopeError("bad_value", f"message carries no {RECORD_KEY!r} record") from None


def load_scenario_dict(scenario_id: str) -> dict[str, Any]:
    path = SCENARIO_DIR / f"{scenario_id}.json"
    if not path.exists():
        raise EnvelopeError("bad_value", f"no scenario {scenario_id!r} in {SCENARIO_DIR}")
    return json.loads(path.read_text(encoding="utf-8"))


def facts_for_party(scenario: dict[str, Any], owners_on_node: tuple[str, ...]) -> dict[str, Any]:
    """Nur die Rohwerte, die auf diesem Knoten liegen duerfen.

    Der Rest des Szenarios wird nicht geladen. Auf dem Knoten `customer`
    existiert `contract_penalty` also nicht im Speicher -- ein Leck ist dort
    nicht verboten, sondern unmoeglich.
    """
    facts = scenario.get("facts") or {}
    return {owner: dict(facts.get(owner, {})) for owner in owners_on_node}
```

```python
"""Der ClientApp, der auf der Maschine einer Partei laeuft.

Start auf dem Rechner der Partei:

    flower-supernode --insecure --superlink 127.0.0.1:9092 \
        --node-config 'party="customer" scenario="s1_pharma_cooling"'

Der Knoten laedt **nur** die Rohwerte der Eigentuemer, die zu seiner Partei
gehoeren, und beantwortet `query.ask_field`. Jede Antwort ist ein projizierter
Skalar oder eine getippte Ablehnung. Ein Modell laeuft hier nicht: eine
Projektion ist eine Funktion, keine Inferenz. Die Partei muss der Foederation
also kein Modell leihen -- was ein guter Teil des Grundes ist, warum sie
ueberhaupt mitmacht.
"""

from __future__ import annotations

from typing import Any, Mapping

from flwr.app import Context, Message
from flwr.clientapp import ClientApp

from .asking import FactStore
from .envelope import EnvelopeError
from .matrix import DEFAULT_THRESHOLDS, visibility
from .wire import (
    facts_for_party,
    fact_record,
    load_scenario_dict,
    read_ask,
    refusal_record,
    unwrap,
    wrap,
)

# Welche Eigentuemer auf welchem Knoten liegen. Eine Tatsache liegt auf genau
# einem Knoten -- das prueft `test_each_party_holds_only_its_own_owners`.
PARTY_FIELDS: dict[str, tuple[str, ...]] = {
    "carrier": ("intake", "legal", "infra"),
    "customer": ("customer",),
    "supplier": ("supplier",),
}

# Welche Rolle dieser Knoten in der Matrix spricht. `carrier` haelt zwei Rollen;
# fuer die Projektion zaehlt der Fragende, nicht der Antwortende, also genuegt
# hier der Eigentuemer des Feldes.
app = ClientApp()


def answer_ask(
    facts: Mapping[str, Mapping[str, Any]],
    party: str,
    asker: str,
    field: str,
    reason_code: str,
    thresholds: Mapping[str, Any],
    flags: tuple[str, ...] = (),
) -> dict[str, Any]:
    """Die Antwort dieses Knotens, als flaches dict (das, was auf den Draht geht).

    Getrennt von der Flower-Nachricht, damit sie ohne SuperLink testbar ist.
    """
    owners_here = PARTY_FIELDS.get(party)
    if owners_here is None:
        return {"role": party, "field": field, "visibility": "none", "value": "",
                "code": "unknown_role", "flags": []}

    store = FactStore(facts, thresholds, flags=flags)
    try:
        owner = store.owner_of(field)
    except EnvelopeError as exc:
        return {"role": party, "field": field, "visibility": "none", "value": "",
                "code": exc.code, "flags": []}

    if owner not in owners_here:
        # Dieser Knoten haelt das Feld nicht. Keine Weiterleitung, keine Suche.
        return {"role": party, "field": field, "visibility": "none", "value": "",
                "code": "unknown_field", "flags": []}

    try:
        sheet = store.answer(asker, owner if owner in store._facts or True else owner, field)
    except EnvelopeError as exc:
        return {"role": party, "field": field, "visibility": "none", "value": "",
                "code": exc.code, "flags": []}

    level = visibility(field, asker)
    value = sheet.fields[field]
    # Durch `fact_record` schicken, damit der Skalar-Riegel auch hier greift.
    try:
        record = fact_record(owner, field, level, value, sheet.flags)
    except EnvelopeError as exc:
        return {"role": party, "field": field, "visibility": "none", "value": "",
                "code": exc.code, "flags": []}
    from .wire import read_reply

    out = read_reply(record)
    out["role"] = owner
    return out


@app.query("ask_field")
def ask_field(message: Message, context: Context) -> Message:
    """Beantworte genau eine Nachfrage nach genau einem Feld."""
    party = str(context.node_config.get("party", "")).strip()
    scenario_id = str(context.node_config.get("scenario", "")).strip()

    try:
        asker, field, reason_code, _incident = read_ask(unwrap(message.content))
    except EnvelopeError as exc:
        return Message(content=wrap(refusal_record(party or "unknown", "?", exc.code)), reply_to=message)

    if party not in PARTY_FIELDS:
        return Message(
            content=wrap(refusal_record(party or "unknown", field, "unknown_role")),
            reply_to=message,
        )

    try:
        scenario = load_scenario_dict(scenario_id)
    except EnvelopeError as exc:
        return Message(content=wrap(refusal_record(party, field, exc.code)), reply_to=message)

    facts = facts_for_party(scenario, PARTY_FIELDS[party])
    thresholds = {**DEFAULT_THRESHOLDS, **(scenario.get("thresholds") or {})}
    flags = tuple(scenario.get("flags") or ())

    reply = answer_ask(facts, party, asker, field, reason_code, thresholds, flags)
    if reply["code"]:
        record = refusal_record(reply["role"] or party, field, reply["code"])
    else:
        record = fact_record(reply["role"], field, reply["visibility"], reply["value"],
                             tuple(reply["flags"]))
    return Message(content=wrap(record), reply_to=message)
```

Sie steht hier nur, damit sichtbar ist, dass der Antwortende der **Eigentümer** ist und nicht der Knotenname: `carrier` beantwortet für `intake`, `legal` und `infra`.

```python
**Ehrlichkeit:** die Reihenfolge der Regeln wurde gegen die sechs bekannten
Faelle geschrieben. 6/6 ist daher eine Konsistenzpruefung, keine Behauptung.
Die Quote ueber die Holdout-Faelle `h1`-`h4`, die der Datenstrang nicht zeigt,
ist die einzige Zahl, die etwas behauptet.
"""

from __future__ import annotations

from typing import Any, Mapping

# In welcher Reihenfolge der Bewerter fragt: (Partei, Feld, Grund).
# `carrier` haelt intake, legal und infra; die zwei anderen je eine Rolle.
ASK_PLAN: tuple[tuple[str, str, str], ...] = (
    ("carrier", "temperature_curve", "safety"),
    ("carrier", "market_sensitive", "confidentiality"),
    ("carrier", "route_weakness", "feasibility"),
    ("supplier", "replacement_available", "feasibility"),
    ("customer", "customer_stock", "time"),
    ("carrier", "contract_penalty", "liability"),
)


def _is(sheets: Mapping[str, Any], field: str, *values: Any) -> bool:
    return sheets.get(field) in values


def decide(
    sheets: Mapping[str, Any], flags: tuple[str, ...], missing: tuple[str, ...]
) -> tuple[tuple[str, ...], str]:
    """Waehle Maßnahmen aus Ampeln, Schwellen und Flags.

    `sheets` bildet Feldname auf projizierten Wert ab. `missing` nennt die
    Parteien, die nicht geantwortet haben. Die Reihenfolge der Regeln ist die
    Reihenfolge der Unumkehrbarkeit: Sicherheit vor Machbarkeit vor Haftung
    vor Kosten.
    """
    # 1 Gefahrgut mit rotem Befund: das Einzige, was zwei Schluessel wert ist.
    if "hazmat" in flags and (
        _is(sheets, "temperature_curve", "rot") or _is(sheets, "route_weakness", "rot")
    ):
        return ("stop_train", "notify_authority"), "safety"

    # 2 Strecke unpassierbar: keine Maßnahme am Zug hilft, er muss herum.
    if _is(sheets, "route_weakness", "rot"):
        return ("alt_transport",), "feasibility"

    # 3 Ladung ausserhalb des Fensters. Umladen nur, wenn es Ersatz gibt.
    if _is(sheets, "temperature_curve", "rot"):
        if _is(sheets, "replacement_available", "gruen", "gelb"):
            return ("cool", "reload"), "safety"
        return ("cool", "hold"), "safety"

    # 4 Eine Partei fehlt und die Ladung ist verderblich: konservativ handeln
    #    und die Luecke nennen. Nicht entscheiden ist keine Option.
    if missing and "perishable" in flags:
        return ("cool", "hold"), "missing_data"

    # 5 Vertragsstrafe ueber der Schwelle, und Umladen ist machbar. Der
    #    Bewerter weiss nicht, wie hoch sie ist -- nur dass sie darueber liegt.
    if _is(sheets, "contract_penalty", "above") and not _is(
        sheets, "replacement_available", "rot"
    ):
        return ("reload",), "liability"

    # 6 Grenzwertig, aber der Kunde hat Bestand: eine teure Maßnahme waere
    #    hier Verschwendung. Das ist die Regel, fuer die die Ampel erfunden ist.
    if _is(sheets, "temperature_curve", "gelb", "gruen") and _is(
        sheets, "customer_stock", "gruen"
    ):
        return ("proceed",), "cost"

    # 7 Nichts Belastbares. Halten ist die umkehrbarste Maßnahme.
    return ("hold",), "missing_data" if (missing or not sheets) else "time"
```

```python
"""Der Bewerter als ServerApp: fragt die Parteiknoten ueber Grid, entscheidet.

Der einzige Agent mit Entscheidungsgewalt und der einzige ohne Rohdaten. Er
haelt in der Matrix **kein** `raw`-Feld: jede Antwort, die hier ankommt, ist
eine Ampel, eine Schwelle oder ein Flag.

Start:

    uv run flwr run . carrier-fed --stream \
        --run-config 'scenario="s1_pharma_cooling"'
"""

from __future__ import annotations

import time
from typing import Any

from flwr.app import ArrayRecord, Context, Message
from flwr.serverapp import Grid, ServerApp

from .envelope import Coverage, Decision, EnvelopeError, digest
from .grants import KEYS_REQUIRED, TIER
from .ledger import Ledger
from .matrix import DEFAULT_THRESHOLDS, visibility
from .policy import ASK_PLAN, decide
from .wire import ASK_FIELD, ask_record, load_scenario_dict, read_reply, unwrap, wrap

app = ServerApp()

# Welche Partei auf welchem Knoten sitzt, erkannt an `--node-config party=...`.
# Der Grid gibt nur Knoten-IDs her, also fragen wir jeden Knoten einmal nach
# seiner Partei -- billiger und robuster, als eine Reihenfolge anzunehmen.
PARTY_PROBE_FIELD = "market_sensitive"


def _party_of_nodes(grid: Grid, ledger: Ledger, incident_id: str) -> dict[str, int]:
    """Ordne jeder Partei ihre Knoten-ID zu, indem jeder Knoten einmal antwortet."""
    node_ids = list(grid.get_node_ids())
    if not node_ids:
        raise EnvelopeError("quota", "no SuperNode is connected to this federation")
    messages = [
        grid.create_message(
            content=wrap(ask_record("assessor", PARTY_PROBE_FIELD, "confidentiality", incident_id)),
            message_type=ASK_FIELD,
            dst_node_id=node_id,
            group_id=str(0),
        )
        for node_id in node_ids
    ]
    found: dict[str, int] = {}
    for reply in grid.send_and_receive(messages, timeout=30.0):
        if reply.has_error():
            continue
        payload = read_reply(unwrap(reply.content))
        # `carrier` antwortet mit dem Eigentuemer `infra`; die anderen
        # antworten `unknown_field`, weil sie das Feld nicht halten.
        party = "carrier" if payload["code"] == "" else None
        node_id = reply.metadata.src_node_id
        if party:
            found["carrier"] = node_id
        else:
            found.setdefault(f"unknown-{node_id}", node_id)
    return found


def run_incident(grid: Grid, ledger: Ledger, scenario: dict[str, Any]) -> Decision:
    """Ein Vorfall: fragen, sammeln, entscheiden, quittieren."""
    report = scenario["report"]
    incident_id = str(report["incident_id"])
    flags = tuple(scenario.get("flags") or ())
    started = time.monotonic()

    ledger._emit(  # noqa: SLF001 - der Ledger ist unser eigener
        "soteria.incident.open",
        {
            "incident_id": incident_id,
            "location": report["location"],
            "cargo_class_coarse": __import__("soteria.matrix", fromlist=["x"]).CARGO_COARSE.get(
                str(report["cargo_class"]), "general"
            ),
            "symptom": report["symptom"],
            "flags": list(flags),
        },
    )

    node_ids = list(grid.get_node_ids())
    if not node_ids:
        raise EnvelopeError("quota", "no SuperNode is connected to this federation")

    # Rundenweise fragen: eine Nachricht je Eintrag im Frageplan, an alle
    # Knoten. Der Knoten, der das Feld nicht haelt, antwortet `unknown_field`
    # -- billig, und es macht die Matrix am Draht sichtbar.
    sheets: dict[str, Any] = {}
    answered_by: set[str] = set()
    asked = 0
    for round_no, (_party, field, reason_code) in enumerate(ASK_PLAN, start=1):
        ledger.require_time(f"asking for {field}", floor=5.0)
        level = visibility(field, "assessor")
        asked += 1
        ledger._emit(  # noqa: SLF001
            "soteria.ask",
            {
                "from_role": "assessor",
                "to_role": _party,
                "field": field,
                "reason_code": reason_code,
                "visibility": level,
            },
        )
        messages = [
            grid.create_message(
                content=wrap(ask_record("assessor", field, reason_code, incident_id)),
                message_type=ASK_FIELD,
                dst_node_id=node_id,
                group_id=str(round_no),
            )
            for node_id in node_ids
        ]
        for reply in grid.send_and_receive(messages, timeout=30.0):
            if reply.has_error():
                ledger.note_refusal("assessor", f"ask {field}", "quota", str(reply.error))
                continue
            payload = read_reply(unwrap(reply.content))
            if payload["code"]:
                # `unknown_field` heisst nur "nicht mein Feld" und ist keine
                # Blockade. Alles andere ist eine, und gehoert auf den Schirm.
                if payload["code"] != "unknown_field":
                    ledger.note_refusal(
                        payload["role"] or "node", f"ask {field}", payload["code"]
                    )
                continue
            sheets[field] = payload["value"]
            answered_by.add(payload["role"])
            ledger._emit(  # noqa: SLF001
                "soteria.fact",
                {
                    "role": payload["role"],
                    "field": field,
                    "visibility": payload["visibility"],
                    "value": payload["value"],
                    "flags": payload["flags"],
                },
            )

    missing = tuple(sorted(set(scenario.get("offline_roles") or ())))
    measures, reason_code = decide(sheets, flags, missing)
    tier = max(TIER[m] for m in measures)
    coverage = Coverage(answered=len(sheets), asked=asked, roles_missing=missing)
    ledger._emit("soteria.coverage", coverage.as_dict())  # noqa: SLF001

    params = {"incident_id": incident_id, "location": report["location"]}
    keys_needed = KEYS_REQUIRED[tier]
    ledger._emit(  # noqa: SLF001
        "soteria.grant.required",
        {"measures": list(measures), "tier": tier, "keys_needed": keys_needed},
    )

    # Freigaben kommen aus dem Szenario, also von Menschen. Task 9 setzt hier
    # `GrantBook.require()` ein; bis dahin werden sie nur gezaehlt.
    granted = tuple(
        str(k["human_id"])
        for k in (scenario.get("keys") or [])
        if str(k.get("measure")) in measures
    )
    for human_id in granted:
        ledger._emit(  # noqa: SLF001
            "soteria.grant.given",
            {
                "measures": list(measures),
                "human_id": human_id,
                "keys_have": len(set(granted)),
                "keys_needed": keys_needed,
            },
        )

    decision = Decision(
        measures=measures,
        params=params,
        tier=tier,
        grants=tuple(sorted(set(granted))),
        coverage=coverage,
        reason_code=reason_code,
        receipt_hash=digest({"measures": list(measures), "params": params, "tier": tier}),
    )
    ledger._emit("soteria.decision", decision.as_dict())  # noqa: SLF001
    ledger._emit(  # noqa: SLF001
        "soteria.done",
        {
            "elapsed_seconds": round(time.monotonic() - started, 2),
            "refusals": ledger.refusals,
            "blocked_tool_calls": 0,
            "asks": asked,
            "answers": len(sheets),
        },
    )
    return decision


@app.main()
def main(grid: Grid, context: Context) -> None:
    """Fahre einen Vorfall gegen die verbundenen Parteiknoten."""
    scenario_id = context.run_config.get("scenario")
    if not isinstance(scenario_id, str) or not scenario_id.strip():
        raise ValueError("run-config 'scenario' must name a file in soteria/scenarios/")
    scenario = load_scenario_dict(scenario_id.strip())

    from .charter import Budget

    seconds = context.run_config.get("budget_seconds")
    budget = Budget(
        max_delegations=12,
        max_depth=2,
        seconds=float(seconds) if isinstance(seconds, (int, float)) and seconds > 0 else 240.0,
        max_connector_calls=0,
    )
    ledger = Ledger(budget, None)

    decision = run_incident(grid, ledger, scenario)

    print(f"\n--- Soteria: {scenario['title']} ---")
    print(f"Maßnahmen: {', '.join(decision.measures)} (Stufe {decision.tier}, {decision.reason_code})")
    print(f"Abdeckung: {decision.coverage.answered}/{decision.coverage.asked}"
          + (f", ohne {', '.join(decision.coverage.roles_missing)}" if decision.coverage.roles_missing else ""))
    print(f"Freigaben: {', '.join(decision.grants) or 'keine noetig'}")
    print(f"Quittung: {decision.receipt_hash}")
    truth = scenario.get("truth") or {}
    if truth:
        hit = set(decision.measures) == set(truth.get("measures") or ())
        print(f"Hinterlegte Wahrheit: {', '.join(truth.get('measures') or [])} -> {'TREFFER' if hit else 'ABWEICHUNG'}")
    print(f"\n{ledger.headline()}")
```

```python
"""Der Beweis: der Rohwert war nie auf dem Draht.

Die Behauptung "keine Partei erfaehrt mehr, als sie darf" ist auf einer Folie
billig. Hier wird sie nachpruefbar: das Skript baut genau die Records, die
zwischen Bewerter und Parteiknoten laufen, serialisiert sie und sucht in den
Bytes nach den Rohwerten.

    uv run python scripts/wire_proof.py

Es benutzt `soteria.wire` und `soteria.party_app`, also denselben Code, den die
Foederation fährt. Nichts ist nachgestellt -- nur der Transport ist hier ein
Aufruf statt eines Sockets, und das steht in der Ehrlichkeitstabelle.
"""

from __future__ import annotations

import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from soteria.matrix import DEFAULT_THRESHOLDS
from soteria.party_app import PARTY_FIELDS, answer_ask
from soteria.wire import facts_for_party, load_scenario_dict

# Die Rohwerte, die niemals im Klartext ueber den Draht gehen duerfen. Als
# String gesucht, weil genau das ein Mitschnitt zeigen wuerde.
def _raw_strings(scenario: dict) -> dict[str, list[str]]:
    out: dict[str, list[str]] = {}
    for owner, group in (scenario.get("facts") or {}).items():
        for field, value in group.items():
            if isinstance(value, dict):
                needles = [str(v) for v in value.values()]
            else:
                needles = [str(value)]
            out[f"{owner}.{field}"] = [n for n in needles if len(n) >= 3 and n not in {"True", "False"}]
    return out


def main() -> int:
    scenario_id = sys.argv[1] if len(sys.argv) > 1 else "s1_pharma_cooling"
    scenario = load_scenario_dict(scenario_id)
    thresholds = {**DEFAULT_THRESHOLDS, **(scenario.get("thresholds") or {})}
    flags = tuple(scenario.get("flags") or ())
    needles = _raw_strings(scenario)

    print(f"Szenario: {scenario['title']}\n")
    print("Was der Bewerter fragt, und was zurueckkommt:")
    print("-" * 78)

    on_the_wire: list[str] = []
    for party, owners_here in PARTY_FIELDS.items():
        facts = facts_for_party(scenario, owners_here)
        for owner, group in facts.items():
            for field in group:
                reply = answer_ask(facts, party, "assessor", field, "safety", thresholds, flags)
                payload = json.dumps(reply, sort_keys=True, default=str)
                on_the_wire.append(payload)
                shown = reply["value"] if not reply["code"] else f"REFUSED {reply['code']}"
                print(f"  assessor -> {party:<9} {field:<22} => {shown}")

    wire = "\n".join(on_the_wire)
    print("-" * 78)
    print("\nSuche die Rohwerte in den Bytes, die den Knoten verlassen haben:\n")

    leaks = 0
    for label, values in sorted(needles.items()):
        for needle in values:
            hit = needle in wire
            mark = "LECK" if hit else "nicht auf dem Draht"
            if hit:
                leaks += 1
            print(f"  {label:<34} {needle[:28]:<30} {mark}")

    print(f"\n{len(on_the_wire)} Antworten, {sum(len(v) for v in needles.values())} Rohwerte geprueft, "
          f"{leaks} davon auf dem Draht.")
    if leaks:
        print("\nFEHLGESCHLAGEN: ein Rohwert hat den Knoten verlassen.", file=sys.stderr)
        return 1
    print("\nBESTANDEN: kein Rohwert hat einen Knoten verlassen. Nicht weil ein Prompt")
    print("es verbietet -- weil die Projektion auf dem Knoten laeuft und der Transport")
    print("nur Skalare traegt.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
from dataclasses import dataclass
from typing import Any, Mapping

from .envelope import MEASURE, ROLES, EnvelopeError, digest


@dataclass(frozen=True)
class Grant:
    """Die Freigabe eines Menschen fuer genau eine Maßnahme mit genau diesen Parametern."""

    measure: str
    params_digest: str
    human_id: str


class GrantBook:
    """Wer was freigegeben hat. Ein Modell kommt hier nicht hinein.

    Zwei Eigenschaften, die dieses Buch garantiert:

    - **Ein Agent erteilt sich keine Freigabe.** `give()` weist jede `human_id`
      zurueck, die ein Rollenname ist. Es gibt keinen Pfad, auf dem ein Modell
      sich selbst eintraegt -- `give()` wird nur aus dem Szenario und von der
      Bedienung aufgerufen, nie aus `team.py` oder `assessor_app.py`.
    - **Eine Freigabe gilt fuer genau diese Parameter.** Der Vergleich laeuft
      ueber `digest(params)`, also unabhaengig von der Schluesselreihenfolge und
      empfindlich fuer jede Aenderung. Ein geaendertes Feld ergibt
      `grant_mismatch`, nicht `no_grant` -- der Unterschied ist die halbe Demo:
      "es lag eine Freigabe vor, aber nicht fuer das hier".
    """

    def __init__(self) -> None:
        self._grants: list[Grant] = []

    def give(self, measure: str, params: Mapping[str, Any], human_id: str) -> Grant:
        if measure not in MEASURE:
            raise EnvelopeError("bad_value", f"{measure!r} is not a measure")
        if not isinstance(human_id, str) or not human_id.strip():
            raise EnvelopeError("no_grant", "a grant needs a human_id")
        if human_id in ROLES:
            raise EnvelopeError(
                "no_grant", f"{human_id!r} is an agent; an agent cannot sign a grant"
            )
        grant = Grant(measure=measure, params_digest=digest(dict(params)), human_id=human_id)
        self._grants.append(grant)
        return grant

    def load(self, keys: list[Mapping[str, Any]]) -> None:
        """Die Freigaben eines Szenarios eintragen -- sie stammen von Menschen."""
        for key in keys or []:
            self.give(str(key.get("measure")), key.get("params") or {}, str(key.get("human_id")))

    def require(self, measures: tuple[str, ...], params: Mapping[str, Any]) -> tuple[str, ...]:
        """Die Schluessel fuer `measures` mit `params`, oder eine getippte Ablehnung."""
        unknown = [m for m in measures if m not in TIER]
        if unknown:
            raise EnvelopeError("bad_value", f"unknown measures {unknown}")
        tier = max(TIER[m] for m in measures)
        needed = KEYS_REQUIRED[tier]
        if needed == 0:
            return ()

        want = digest(dict(params))
        relevant = [g for g in self._grants if g.measure in measures]
        matching = sorted({g.human_id for g in relevant if g.params_digest == want})
        if len(matching) >= needed:
            return tuple(matching[:needed])

        others = sorted({g.human_id for g in relevant if g.params_digest != want})
        if others:
            raise EnvelopeError(
                "grant_mismatch",
                f"{others} signed {measures} for different parameters; "
                f"this decision carries {sorted(params)}",
            )
        raise EnvelopeError(
            "no_grant",
            f"tier {tier} needs {needed} distinct human grants for {measures}, "
            f"{len(matching)} present",
        )
```

```python
    # Alles, was Bytes vom Rechner traegt, plus die Presse als Maßnahme. Der
    # geerbte Charter kennt nur Connectors; `press` ist eine Entscheidung, aber
    # sie verlaesst das Haus genauso.
    OUTBOUND_CHANNELS = frozenset(OUTBOUND_CONNECTORS) | {"press"}

    def emit(self, kind: str, payload: dict[str, Any]) -> None:
        """Oeffentliche Fassung von `_emit`, fuer die Soteria-Ereignisse."""
        self._emit(kind, payload)

    @property
    def quarantined(self) -> bool:
        return self._quarantine_trigger is not None

    @property
    def blocked_channels(self) -> tuple[str, ...]:
        return tuple(sorted(self.OUTBOUND_CHANNELS)) if self.quarantined else ()

    def mark_market_sensitive(self, role_name: str, field: str) -> None:
        """Eine kursrelevante Tatsache ist gelesen. Ab jetzt gilt sie fuer den Rest des Laufs.

        Einmal angekuendigt, nicht je Versuch -- die Ansicht braucht ein Banner,
        keine Lawine. Die Versuche selbst zaehlt `check_outbound` als Ablehnungen.
        """
        if self._quarantine_trigger is not None:
            return
        self._quarantine_trigger = (role_name, field)
        # Auch die geerbte Taint-Regel scharf machen, damit eine Uebergabe an
        # eine Rolle mit Ausgangswerkzeug ebenfalls faellt.
        self.mark_tainted(role_name)
        self._emit(
            "soteria.quarantine",
            {
                "trigger_role": role_name,
                "field": field,
                "blocked_channels": list(self.blocked_channels),
            },
        )

    def check_outbound(self, actor: str, channel: str) -> None:
        """Verweigere jeden ausgehenden Kanal, solange Quarantaene gilt.

        Ein Kanal, der keine Bytes nach draussen traegt, laeuft durch. Die
        Pruefung ist bewusst grob: sie sieht keinen String an, also gibt es
        nichts, was sich umformulieren liesse.
        """
        if not self.quarantined or channel not in self.OUTBOUND_CHANNELS:
            return
        trigger_role, field = self._quarantine_trigger  # type: ignore[misc]
        detail = (
            f"{channel} is shut for the rest of this run: {trigger_role} read "
            f"{field}, which is market sensitive"
        )
        self.note_refusal(actor, channel, "quarantine", detail)
        raise EnvelopeError("quarantine", detail)
```

```python
"""Verkettete Quittungen. Jede haelt den Kopf der vorherigen.

Eine einzelne Quittung sagt "das ist passiert". Eine Kette sagt zusaetzlich
"und nichts davor wurde nachtraeglich geaendert" -- denn jeder Eintrag geht in
den Hash des naechsten ein. `verify()` rechnet die Kette nach; ein geaendertes
Feld irgendwo in der Mitte faellt auf.

Der Hash ist auf 16 Hex-Zeichen gekuerzt (`envelope.digest`). Das ist keine
Kryptografie fuer den Ernstfall, sondern eine Pruefsumme, die auf eine Folie
passt. Das steht so in der Ehrlichkeitstabelle.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Mapping

from .envelope import digest

GENESIS = "0" * 16


@dataclass(frozen=True)
class Receipt:
    seq: int
    kind: str
    payload_digest: str
    prev: str
    hash: str


class ReceiptChain:
    def __init__(self) -> None:
        self._receipts: list[Receipt] = []

    @property
    def head(self) -> str:
        return self._receipts[-1].hash if self._receipts else GENESIS

    @staticmethod
    def _link(seq: int, kind: str, payload_digest: str, prev: str) -> str:
        return digest({"seq": seq, "kind": kind, "payload": payload_digest, "prev": prev})

    def append(self, kind: str, payload: Mapping[str, Any]) -> Receipt:
        seq = len(self._receipts) + 1
        payload_digest = digest(dict(payload))
        prev = self.head
        receipt = Receipt(
            seq=seq,
            kind=kind,
            payload_digest=payload_digest,
            prev=prev,
            hash=self._link(seq, kind, payload_digest, prev),
        )
        self._receipts.append(receipt)
        return receipt

    def verify(self) -> bool:
        prev = GENESIS
        for i, receipt in enumerate(self._receipts, start=1):
            if receipt.seq != i or receipt.prev != prev:
                return False
            if receipt.hash != self._link(receipt.seq, receipt.kind, receipt.payload_digest, prev):
                return False
            prev = receipt.hash
        return True

    def as_list(self) -> list[dict[str, Any]]:
        return [
            {"seq_in_chain": r.seq, "kind": r.kind, "hash": r.hash, "prev": r.prev}
            for r in self._receipts
        ]
```

```python
"""Was zu tun ist, wenn eine Partei nicht antwortet.

Der konservative Rueckfall ist eine **Tabelle**, keine Konstante. "Im Zweifel
halten" ist bei Gefahrgut die falsche Antwort und bei Maschinenteilen eine
teure. Die Tabelle steht hier, damit ein Mensch sie lesen und bestreiten kann
-- und damit sie in der Praesentation zu sehen ist.

Grenze nach oben: ohne Daten loest niemand Stufe 3 aus. Die einzige Ausnahme
ist Gefahrgut, wo Nichtwissen selbst der Grund zum Anhalten ist.
"""

from __future__ import annotations

from .envelope import EnvelopeError

# Nach Flag, in absteigender Vorrangigkeit geprueft.
FALLBACK: dict[str, tuple[str, ...]] = {
    # Nichtwissen ueber eine Gefahrgutladung ist selbst der Grund zum Anhalten.
    "hazmat": ("stop_train", "notify_authority"),
    # Verderbliches: kuehlen kostet wenig und haelt alle Optionen offen.
    "perishable": ("cool", "hold"),
    # Kursrelevant: halten und nichts nach draussen geben.
    "market_sensitive": ("hold",),
    "person_data": ("hold",),
    # Alles andere: die umkehrbarste Maßnahme.
    "default": ("hold",),
}

_PRECEDENCE = ("hazmat", "perishable", "market_sensitive", "person_data")


def conservative(
    flags: tuple[str, ...], missing: tuple[str, ...]
) -> tuple[tuple[str, ...], str]:
    """Die Maßnahme, wenn `missing` nicht leer ist.

    Wirft `bad_value`, wenn niemand fehlt -- dann ist der Rueckfall nicht
    zustaendig und `policy.decide()` haette entscheiden muessen.
    """
    if not missing:
        raise EnvelopeError(
            "bad_value", "the fallback is only for incomplete coverage; nobody is missing"
        )
    for flag in _PRECEDENCE:
        if flag in flags:
            return FALLBACK[flag], "missing_data"
    return FALLBACK["default"], "missing_data"
```

```python
def _decision_from(events: list[dict]) -> dict | None:
    for event in reversed(events):
        if event["type"] == "soteria.decision":
            return event
    return None


def main() -> int:

    for path in sorted(SCENARIOS.glob("*.json")):
        scenario_id = path.stem
        started = time.monotonic()

        seconds = round(time.monotonic() - started, 3)
        events = data["events"]
        truth = (data["scenario"].get("truth") or {})

    holdout = [c for c in cases if c["holdout"]]
```

```python
"""Die Modellseite: fuenf Rollen, ein Modell, derselbe Umschlag.

Der ServerApp in `assessor_app.py` entscheidet mit einer Regelmaschine -- das
ist reproduzierbar und liefert die Zahlen. Diese AgentApp fährt dieselbe
Ask-Schleife mit einem Modell, damit die Zusammenarbeit als Zusammenarbeit zu
sehen ist. Beide benutzen `matrix.py`, `envelope.py` und `grants.py`
unveraendert; nur der Bewerter ist einmal eine Funktion und einmal ein Modell.

    uv run flwr run . supergrid --stream --run-config 'scenario="s1_pharma_cooling"'
"""

from __future__ import annotations

import json
from dataclasses import replace
from typing import Any

from flwr.agentapp import AgentApp, AgentSession
from flwr.app import Context

from .asking import ASK_PREFIX, FactStore, ask_tool, askable_fields
from .charter import Budget
from .envelope import REASON, EnvelopeError, ROLES
from .grants import GrantBook
from .ledger import Ledger
from .matrix import DEFAULT_THRESHOLDS, visibility
from .roles import SOTERIA
from .team import Team, runtime_client
from .wire import load_scenario_dict

app = AgentApp()


class SoteriaTeam(Team):
    """Ein `Team`, dessen Uebergabe `ask_<rolle>(field, reason_code)` ist.

    Ueberschreibt genau zwei Stellen des geerbten Harness: welche Werkzeuge eine
    Rolle bekommt, und was beim Aufruf passiert. Alles andere -- Budget, Uhr,
    Quittungen, leere Antworten, Ablehnungen -- bleibt der geprueften Code aus
    `team.py`.
    """

    def __init__(self, *args: Any, store: FactStore, **kwargs: Any) -> None:
        super().__init__(*args, **kwargs)
        self._store = store

    def _tools_for(self, role):  # type: ignore[no-untyped-def]
        schemas: list[dict[str, Any]] = []
        names: set[str] = set()
        for target in role.may_delegate_to:
            fields = askable_fields(target)
            if not fields:
                continue
            schema = ask_tool(target, fields)
            names.add(schema["name"])
            schemas.append(schema)
        # Keine Connectors: alle Daten sind lokale Fixtures.
        return schemas, set(), names

    def _delegate(self, call, caller, name, call_id, depth, hop):  # type: ignore[no-untyped-def]
        target = name[len(ASK_PREFIX):]
        args = call.get("arguments")
        if isinstance(args, str):
            try:
                args = json.loads(args)
            except json.JSONDecodeError:
                return self._refuse(call_id, caller.name, name, "bad_value")
        if not isinstance(args, dict):
            args = {}
        field = str(args.get("field") or "")
        reason_code = str(args.get("reason_code") or "")
        if reason_code not in REASON:
            return self._refuse(call_id, caller.name, f"{name} {field}", "bad_value")
        if target not in caller.may_delegate_to:
            return self._refuse(call_id, caller.name, f"{name} {field}", "not_in_matrix")

        try:
            sheet = self._store.answer(caller.name, target, field)
        except EnvelopeError as exc:
            return self._refuse(call_id, caller.name, f"{name} {field}", exc.code, exc.detail)

        level = visibility(field, caller.name)
        self._ledger.note_fact(sheet, field, level)
        if field == "market_sensitive" and bool(sheet.fields[field]):
            self._ledger.mark_market_sensitive(target, field)
        return {
            "type": "function_call_output",
            "call_id": call_id,
            "output": json.dumps(sheet.as_dict(), default=str),
        }

    def _refuse(self, call_id: str, actor: str, action: str, code: str, detail: str = ""):  # type: ignore[no-untyped-def]
        self._ledger.note_refusal(actor, action, code, detail)
        return {
            "type": "function_call_output",
            "call_id": call_id,
            "output": json.dumps({"refusal": code}),
        }


@app.main()
def main(agent: AgentSession, context: Context) -> None:
    """Fahre einen Vorfall mit dem Modell als Bewerter."""
    scenario_id = context.run_config.get("scenario")
    if not isinstance(scenario_id, str) or not scenario_id.strip():
        raise ValueError("run-config 'scenario' must name a file in soteria/scenarios/")
    model = context.run_config.get("agent.model") or context.run_config.get("model")
    if not isinstance(model, str) or not model.strip():
        raise ValueError("run-config 'agent.model' must be a non-empty string")

    scenario = load_scenario_dict(scenario_id.strip())
    thresholds = {**DEFAULT_THRESHOLDS, **(scenario.get("thresholds") or {})}
    store = FactStore(
        scenario.get("facts") or {},
        thresholds,
        offline_roles=tuple(scenario.get("offline_roles") or ()),
        flags=tuple(scenario.get("flags") or ()),
    )

    charter = SOTERIA
    override = context.run_config.get("budget_seconds")
    if isinstance(override, (int, float)) and override > 0:
        charter = replace(charter, budget=replace(charter.budget, seconds=float(override)))

    ledger = Ledger(charter.budget, agent.events)
    book = GrantBook()
    book.load(scenario.get("keys") or [])

    report = scenario["report"]
    task = (
        f"Vorfall {report['incident_id']} an {report['location']}: {report['symptom']}. "
        "Frage die Rollen nach den Feldern, die du brauchst, und entscheide dann. "
        "Nenne genau die Maßnahmen aus der erlaubten Liste, ihre Stufe und einen "
        "getippten Grund. Wenn eine Rolle nicht antwortet, entscheide trotzdem und "
        "nenne die Abdeckung."
    )

    team = SoteriaTeam(
        charter=charter,
        client=runtime_client(),
        model=model.strip(),
        ledger=ledger,
        connectors=None,
        store=store,
    )
    root = ledger.open_hop("user", charter.supervisor, task, depth=0, billable=False)
    try:
        answer = team.run(task, hop=root)
    except Exception as exc:
        ledger.close_hop(root, "error", str(exc))
        print(f"Lauf fehlgeschlagen: {exc}")
        print(f"\n{ledger.headline()}")
        raise
    ledger.close_hop(root, "ok")

    print(answer)
    print("\n--- Soteria: Grenze, Stufen, Quittungen ---")
    print(charter.delegation_graph())
    print()
    print(ledger.transcript())
    print(f"\n{ledger.headline()}")
    print(f"Ablehnungen nach Code: {ledger.refusal_codes or 'keine'}")
```

Beim Ausführen zuerst lesen. Diese Punkte sind Widersprüche zwischen v1 und v2, keine Meinungsfragen.

**1. Task 8 entfällt.** In v1 hieß Task 8 „`policy.py` + `incident.py` + `incident_demo.py`". Absichtlich: `run_incident` braucht einen Grid, und die Attrappe dafür ist `_LocalGrid` aus `scripts/record_run.py` (Task 12).
